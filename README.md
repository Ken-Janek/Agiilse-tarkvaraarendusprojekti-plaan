Lihtne ülesannete halduri veebirakendus, mis on loodud agiilse arendusprojekti näidiseks.

## Mida see teeb

- lisab uusi ülesandeid
- märgib ülesanded tehtuks
- filtreerib ülesandeid staatuse järgi
- otsib ülesandeid pealkirja või sõnumi järgi
- salvestab andmed brauseri `localStorage`-i
